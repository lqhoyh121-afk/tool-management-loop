# Tool Management Loop

基于钉钉的工器具线上借还工作流。当前处于规划与基础检查阶段，**业务程序尚未实现，不能用于生产办理**。

## 首版目标

Windows 上双击部署入口，导入使用者自己的真实台账并完成授权配置；员工通过钉钉收集表申请，管理人通过关联待办确认，脚本完成预留、借还记录和提醒。

- 一单一种工具，可多件，整笔归还。
- 审批、借出确认、归还确认分别留痕，不由 Agent 代办。
- 提前一天提醒，逾期每天一次；归还待确认暂停催办，不催管理员。
- 固定业务全脚本优先，钉钉为固定平台，不接其他企业业务系统。
- 先在主控本机验收，再验证异机迁移；外部协作者不操作主控机器、凭据和真实台账。

## 当前可以运行什么

仅运行仓库安全检查和其单元测试，不会连接钉钉或发消息：

```text
python scripts/repo_guard.py
python -m unittest discover -s tests -p "test_*.py" -v
```

本地使用 Python 3.11 或更新版本执行以上标准库检查。首次克隆后安装本地提交钩子：

```text
python scripts/install_hooks.py
```

本地钩子不是完整安全边界，远程 CI 才是合并检查依据。公开仓库不得放真实数据、账号配置、个人绝对路径或文档署名；Git 作者记录正常保留。当前未指定开源许可证，公开可见不等于授予额外使用许可。
