# T01 隔离表准备进度

> 历史阶段记录：当时状态已由 [最终交接报告](T01-HANDOFF.md) 更新；不作为当前验收或资源状态。

## 授权及实际写入

使用者明确授权仅在临时表设置专用测试库存，用于解除原可借条件与申请之间的测试数据冲突；具体数量不公开。此授权不改变正式台账，也不证明实物库存。

- 建立一个本轮命名的隔离 Base；创建前按同名检索，结果为空且 hasMore=false；创建后按返回 baseId 独立 GET，核对 ID 和名称。
- 新建“隔离测试库存”“借用申请测试”两张数据表，分别回读字段并核对名称与类型。Base 创建时另自动带出两张默认数据表，未改写它们；最终清理按本轮 Base 精确范围处理。
- 库存表写入一条使用者授权的测试库存，包含名称、规格、测试可借数量及测试性质说明。申请表尚未代填任何申请。
- 库存记录独立全量回读，recordId 与创建响应 newRecordIds 精确关联；刷新字段映射后核对全部业务字段。number 字段真实返回字符串，使用十进制解析核对其与授权数量一致；初次直接以字符串与整数比较未通过，未重写记录，而是查明类型后重新只读核验通过。

## 证据保管

原始非凭据回执和精确资源清单仅保存在使用者授权的本机私有目录。现有 Git 忽略规则已核验生效；目录 ACL 已移除继承并回读确认仅当前系统用户与 SYSTEM 具完全权限。该 ACL 不抵御系统管理员控制，不宣称绝对隔离。未存放令牌或密码。
